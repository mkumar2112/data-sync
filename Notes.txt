1. pip install
    pip install fastapi uvicorn[standard] python-dotenv sqlalchemy pymysql psycopg2-binary cryptography

    Run :- uvicorn backend.src.main:app --reload

    initialize Alembic:
        python -m alembic init alembic
    
    autogenerate migrations
        python -m alembic revision --autogenerate -m "main_db models"

    Apply migration:
        python -m alembic upgrade head

    Alembic to accept current schema as baseline:
        python -m alembic stamp head

    Kill Port 8000 in Window
        Get-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess | Stop-Process -Force





2. Install Next Js for UI 
    npx create-next-app@latest frontend

    Run :- npm run dev




DB Query
    1.) Truncate all table in db 

        DO
        $$
        DECLARE
            r RECORD;
        BEGIN
            FOR r IN (SELECT tablename FROM pg_tables WHERE schemaname = 'public')
            LOOP
                EXECUTE 'TRUNCATE TABLE public.' || quote_ident(r.tablename) || ' RESTART IDENTITY CASCADE';
            END LOOP;
        END
        $$;
